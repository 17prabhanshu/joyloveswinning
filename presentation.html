Beyond FirmHive

While academic frameworks like BJTU's FirmHive proved that LLMs can act as autonomous security analysts, they stop at discovery. PS3 Agent bridges the gap between theoretical vulnerability mapping and production-ready, interactive remediation.

The Academic Baseline

FirmHive (BJTU SecurityLab)

  • 1

    Tree of Agents (ToA)

    Hierarchical LLM orchestration for decentralized firmware analysis.

  • 2

    Proactive Knowledge Hub

    Static global memory tracking dependencies to mitigate context limits.

  • 3

    CLI-Driven Output

    Generates static reports and logs designed for academic review.

Our Implementation

PS3 Autonomous Red-Team Agent

  • 1

    Recursive AST + Behavior Graph

    Dynamically parses C code to map hardware I/O boundaries and state transitions into a live, traversable graph.

  • 2

    Closed-Loop Autonomous Auto-Patching

    We don't just find the bug. The agent synthesizes a patch, injects it into the C source code, and verifies it against the simulator.

  • 3

    Awwwards-Tier Interactive Interface

    A gorgeous glassmorphic React UI featuring the "Grill Me" cross-examination chat, retro CRT animations, and local Ollama fallback execution.

The PS3 Execution Workflow

01. INGEST

AST Extraction

Firmware is parsed. Boundary conditions and memory states are mapped.

02. HUNT

Adaptive Planner

LLM analyzes the Behavior Graph and proposes adversarial test payloads.

03. VERIFY

Deterministic Simulator

Payloads run against Renode virtual hardware. Hard truth, zero hallucinations.

04. PATCH

Auto-Remediation

Failures trigger Root Cause Analysis, and the AI rewrites the vulnerable C code.
